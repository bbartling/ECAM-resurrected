# Archived v4 prototype

This directory preserves the earlier ECAM Resurrected v4 Python prototype as
historical material. Its contents were moved from the former repository root
without modification. This archive is not maintained as the current project,
and its package is not installed or discovered by the root `ecam-mv` project.

The prototype's `ecam_resurrected` import, `ecam-resurrected` command,
Tkinter interface, and Windows launchers belong to its original environment.
They are not interfaces provided by current `ecam-mv`. The archived
`pyproject.toml`, dependency files, and documentation describe that prototype;
they do not control installation from the repository root. The archive's
original MIT license remains at `legacy_v4/LICENSE`. The root project has its
own Apache-2.0 license; the v4 archive has not been relicensed.

Use the root [migration guide](../docs/MIGRATION.md) and
[project README](../README.md) for the current package and commands.
